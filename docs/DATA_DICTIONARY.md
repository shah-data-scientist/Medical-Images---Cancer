# Data Dictionary

**Project:** BrainScanAI - Brain Tumor Detection
**Last Updated:** 2026-01-15
**Status:** Stable

---

## 1. Input Data (`data/`)

### MRI Images
*   **Format:** JPEG / PNG
*   **Resolution:** 512x512 pixels (resized to 224x224 during preprocessing)
*   **Channels:** Grayscale or RGB (converted to RGB 3-channel for ResNet50)
*   **Classes:**
    *   `Normal` (0): Healthy brain tissue.
    *   `Cancer` (1): Visible brain tumor presence.

---

## 2. Processed Features (`features/`)

### `metadata.csv`
Master index of all images used in the pipeline.

| Column | Type | Description |
| :--- | :--- | :--- |
| `image_path` | String | Relative path to source image (e.g., `data/labelled/yes/Y1.jpg`) |
| `label` | Integer | Ground truth label: `0` (Normal), `1` (Cancer), or `-1` (Unknown/Unlabeled) |
| `split` | String | Data split assignment: `'train'`, `'val'`, `'test'`, or `'unlabeled'` |

### `resnet50_features.npy`
*   **Description:** Deep features extracted from ResNet50 (Average Pooling layer).
*   **Dimensions:** `(N_samples, 2048)`
*   **Data Type:** `float32`
*   **Normalization:** Standard ImageNet normalization applied before extraction.

### `features_pca_50.npy`
*   **Description:** PCA-reduced feature vectors used for training.
*   **Dimensions:** `(N_samples, 50)`
*   **Data Type:** `float32`
*   **Variance Retained:** >95%

### `labels.npy`
*   **Description:** Aligned array of ground truth labels corresponding to feature rows.
*   **Dimensions:** `(N_samples,)`
*   **Values:** `0`, `1`, or `-1`.

---

## 3. Generated Labels (`features/`)

### `weak_labels.csv`
Generated by Unsupervised Analysis (Notebook 2) using K-Means clustering.

| Column | Type | Description |
| :--- | :--- | :--- |
| `weak_label` | Integer | Predicted cluster label (`0` or `1`) |
| `confidence` | Float | Distance to cluster centroid (lower distance = higher confidence, normalized to 0-1 range) |
| `original_index` | Integer | Index in the original `unlabeled` dataset |

---

## 4. Model Outputs (`results/metrics/`)

### `detailed_cv_results.json`
Contains raw metrics for every fold of cross-validation.

*   **Structure:** JSON Object
*   **Key Fields:**
    *   `fold_X`: Object containing `accuracy`, `precision`, `recall`, `f2_score`.
    *   `mean_metrics`: Aggregated performance across 5 folds.

### `scenario_comparison.csv`
High-level comparison of the 3 experimental scenarios.

| Column | Type | Description |
| :--- | :--- | :--- |
| `Scenario` | String | Name (A, B, or C) |
| `F2 Score` | Float | Mean F2 score (beta=2) |
| `Recall` | Float | Mean Recall |
| `Std Dev` | Float | Standard deviation of F2 score across folds |

---

## 5. Notes on Data Handling

*   **No PII:** Input images are scrubbed of DICOM metadata headers. Only pixel data is used.
*   **Splitting Strategy:** Stratified 80/20 split used for labeled data. Unlabeled data is used entirely for pre-training.
