## 🚀 Running the Notebooks

```bash

```

Then:
1. Open any notebook (`1_feature_extraction.ipynb`, etc.)
2. Click the kernel name (top right)
3. Select **"BrainScanAI (Poetry)"**
4. Run cells as normal

### Option 2: Jupyter Notebook (Classic)

```bash
# Start classic Jupyter Notebook
poetry run jupyter notebook
```

Same steps as Option 1 to select the kernel.

### Option 3: VS Code

1. Open the project folder in VS Code
2. Install Python extension (if not already)
3. Open any `.ipynb` file
4. Click "Select Kernel" (top right)
5. Choose **"BrainScanAI (Poetry)"**
6. Run cells

## 🐛 Troubleshooting

### Issue: "Kernel not found"
**Solution**:
```bash
# Reinstall kernel
poetry run python -m ipykernel install --user --name=brainscanai --display-name="BrainScanAI (Poetry)"
```

### Issue: "Module not found"
**Solution**:
```bash
# Verify environment
poetry run python -c "import torch; print(torch.__version__)"

# If missing, reinstall
poetry install
```

### Issue: Permission errors with images
**Possible causes**:
- OneDrive sync in progress
- Files opened in another program
- Antivirus scanning

**Solution**:
- Wait for OneDrive sync to complete
- Close image viewers
- Temporarily disable file scanning

### Issue: Notebook hangs/freezes
**Solution**:
- Reduce batch size in code
- Restart Jupyter kernel
- Check Task Manager for memory usage
